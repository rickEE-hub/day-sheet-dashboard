The fair queue

First in, first seated

Players are never told a table at check-in. The queue fills the next free seat in arrival order, so friends don’t just play each other.

Seats refill a minute after a game ends

The host can still seat someone by hand

A paused table is skipped

Operator playbook

A day at the chess desk

Before doors

  • Log in to the operator screen
  • All 6 tables show “Screen online”
  • Leaderboard is up and live
  • Event tab: challenge open

During the show

  • Check players in, add to queue
  • Call seated players over
  • Press Start game
  • Help players, watch the clocks

End of day

  • Close the challenge
  • Let last games finish
  • Fix any names, export CSV
  • Today’s top 10 resets at midnight

Wed 11 Nov, 7pm
